# Riffle 설치하고 처음 써 보기

컴퓨터에 익숙하지 않아도 그대로 따라 할 수 있게 썼습니다. 순서대로만 하면 됩니다.

**Riffle이 하는 일은 두 가지입니다.**

- **문서 합치기** — 여러 PDF에서 필요한 쪽만 골라 원하는 순서로 새 PDF를 만듭니다.
- **필기 옮기기** — Samsung Notes·Notewise·Goodnotes 6에 해 둔 필기를, 배경 PDF만 새것으로
  바꿔 그대로 옮깁니다. 교재가 개정판으로 바뀌었을 때 필기를 다시 하지 않아도 됩니다.

> **설치한 앱에서는 파일이 이 컴퓨터 밖으로 나가지 않습니다.** 문서를 서버에 올리지 않고 내 PC
> 안에서만 처리합니다. 인터넷은 설치할 때만 씁니다.
>
> 설치할 수 없는 기기(Mac·태블릿·다른 사람 PC)에서는 아래 «설치 없이 웹으로 쓰기»를 보세요.
> 웹은 파일을 서버에 올려 처리한다는 점이 다릅니다.

---

## 준비물

- **Windows 10 또는 11** (64비트)
- 인터넷 연결 (설치할 때만)

Python 같은 걸 따로 깔 필요는 **없습니다.** 설치 파일 안에 다 들어 있습니다.

---

## 1단계 · 설치하기

두 가지 방법이 있습니다. **방법 A를 권합니다.**

### 방법 A · 파일 하나 받아서 설치하기 (권장)

1. 아래 주소를 눌러 다운로드 페이지를 엽니다.

   **<https://github.com/kynbeen/riffle/releases/latest>**

2. 페이지를 아래로 내리면 **Assets**(첨부 파일) 목록이 있습니다.
   거기서 이름이 이렇게 생긴 파일을 누릅니다.

   ```
   Riffle-Setup-1.0.0.exe
   ```

   (`1.0.0` 자리 숫자는 버전에 따라 다릅니다. **`.exe`로 끝나는 파일**을 고르면 됩니다.
   `Source code (zip)`은 개발자용이니 누르지 마세요.)

3. 다운로드된 파일을 **두 번 눌러 실행**합니다.

4. **여기서 파란 경고창이 뜹니다. 정상입니다.** ⬇︎ 아래 «파란 경고창이 떴어요»를 보세요.

5. 「사용자 계정 컨트롤」 창이 뜨면 **[예]** 를 누릅니다.

6. 설치 마법사에서 계속 **[다음]** 을 누르고 마지막에 **[설치]** 를 누릅니다.

7. 끝났습니다. 바탕화면과 시작 메뉴에 **Riffle** 아이콘이 생깁니다.

### 방법 B · 명령 한 줄로 한 번에 (원터치)

직접 다운로드하고 실행하는 과정을 한 번에 끝냅니다.

1. 키보드에서 **Windows 키**를 누르고 `powershell` 이라고 칩니다.
2. **Windows PowerShell** 을 눌러 엽니다.
3. 아래 줄을 **통째로 복사해서** 붙여넣고 **Enter** 를 누릅니다.

```powershell
iwr https://raw.githubusercontent.com/kynbeen/riffle/main/install-online.ps1 -OutFile "$env:TEMP\Riffle-install.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\Riffle-install.ps1"
```

최신 버전을 찾아 내려받고 설치까지 알아서 합니다. 중간에 「사용자 계정 컨트롤」 창이 뜨면
**[예]** 를 누르세요. `설치가 끝났습니다` 가 나오면 완료입니다.

> 이 명령이 하는 일은 **최신 릴리스 조회 → 설치 파일 내려받기 → 실행**, 이 세 가지가
> 전부입니다. 내용이 궁금하면
> [`install-online.ps1`](../install-online.ps1) 을 먼저 읽어 보셔도 됩니다.

## 파란 경고창이 떴어요

**「Windows의 PC 보호」** 라는 파란 창이 뜨고 실행이 막힐 수 있습니다.

> Windows에서 PC를 보호했습니다
> Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.

**바이러스라는 뜻이 아닙니다.** 유료 코드 서명 인증서를 사지 않은 프로그램에는 Windows가
일단 이 경고를 띄웁니다. 개인이 만든 프로그램은 대부분 이 화면을 만납니다.

**넘어가는 방법:**

1. 창 안의 **「추가 정보」** 를 누릅니다. (작은 글씨입니다)
2. 아래에 나타나는 **[실행]** 버튼을 누릅니다.

백신 프로그램이 파일을 지워 버리는 경우도 드물게 있습니다. 그럴 때는 백신에서
`Riffle-Setup-….exe` 를 예외로 등록한 뒤 다시 받으세요.

### 설치 없이 웹으로 쓰기

브라우저에서 아래 주소를 엽니다. 화면과 하는 일은 설치한 앱과 같습니다.

**<https://useriffle.onrender.com>**

- 한동안 아무도 쓰지 않았으면 서버가 잠들어 있어, 처음 열 때 **30초~1분쯤** 걸릴 수 있습니다.
- 올린 파일은 나만 볼 수 있는 임시 공간에 들어가고, 1시간 쓰지 않거나 왼쪽 위 **←** 를 누르면 지워집니다.
  결과 파일은 만들자마자 내려받기로 넘겨주고 서버에 남기지 않습니다.
- 파일 하나는 100MB까지 올릴 수 있습니다.
- 주소창 옆 설치 단추(또는 브라우저 메뉴의 «앱 설치»)를 누르면 앱처럼 따로 창으로 열 수 있습니다.

## 2단계 · 실행하기

바탕화면이나 시작 메뉴의 **Riffle** 아이콘을 누르면 화면을 꽉 채운 창으로 열립니다. 내 PC 안에서만 돌아가고,
파일이 인터넷으로 올라가지 않습니다.

(예전 판에 있던 **Riffle 로컬 웹** 아이콘은 2026-09-26 없앴습니다. 다시 설치하면 그 아이콘도 지워집니다.)

## 3단계 · 써 보기

창이 열리면 **「파일을 여기에 놓으세요」** 한 곳만 보입니다. 파일을 끌어다 놓거나
**[파일 고르기]** 로 고르면, 놓은 파일을 보고 할 일을 알아서 정합니다.

| 놓은 것 | 열리는 일 |
|---|---|
| 필기 파일 하나 + 새 PDF 하나 | 필기 옮기기 |
| PDF 여러 개 | 문서 합치기 |
| PDF 하나만 | 기다립니다 — 필기 파일이나 PDF를 하나 더 놓으세요 |

처음으로 돌아가려면 왼쪽 위 **←** 를 누릅니다.

### PDF 여러 개를 하나로 합치기

1. PDF를 두 개 이상 놓습니다. 놓은 순서대로 **모든 쪽**이 아래 결과 줄에 들어갑니다.
2. 빼고 싶은 쪽은 문서의 쪽 그림을 눌러 뺍니다. `1-3, 5, 8-` 처럼 범위 칸에 적어도 됩니다.
3. 순서를 바꾸려면 결과 줄에서 쪽을 끌거나 `‹` `›` 를 누릅니다.
4. 문서를 더하려면 **[PDF 더하기]** 를 누르거나 파일을 더 놓습니다.
5. **[PDF로 저장]** 을 누릅니다.

원본 PDF는 **하나도 바뀌지 않습니다.** 새 파일이 따로 생깁니다.

### 필기를 새 교재로 옮기기

1. **옛 필기 파일**과 필기를 옮겨 붙일 **새 PDF**(예: 개정판 교재)를 함께 놓습니다.
   - Samsung Notes → `.sdocx`
   - Notewise → `.notewise`
   - **Goodnotes 6 → `.goodnotes`**
2. 잠시 기다리면 두 문서의 쪽을 **자동으로 짝지어** 줍니다. 쪽이 늘거나 줄어도, 여백이나
   크기가 달라져도 본문을 기준으로 맞춥니다.
3. 기계가 자신 없는 쪽만 **카드**로 나옵니다. 카드마다 이유가 한 줄 있고, 옛 쪽과 새 쪽에
   필기를 겹쳐 보여 줍니다.
   - 제자리면 **[맞아요]**
   - 짝이 틀렸으면 **[다른 쪽]** 을 눌러 새 PDF의 맞는 쪽을 고릅니다
   - 결과에 필요 없으면 **[빼기]**
4. **[새 파일로 저장]** 을 누르면 원본과 **같은 형식**으로 새 파일이 나옵니다. 카드가 없으면
   바로 저장하면 됩니다.

원본 필기 파일과 PDF는 **건드리지 않습니다.** 새 파일만 생깁니다.

### Goodnotes 6에서 `.goodnotes` 파일 꺼내기

Riffle에 넣으려면 Goodnotes 앱에서 먼저 파일로 내보내야 합니다.

1. Goodnotes 6에서 옮기고 싶은 **노트를 엽니다.**
2. **공유 / 내보내기** 메뉴를 엽니다.
3. 형식에서 **PDF가 아니라 「Goodnotes 문서」** 를 고릅니다.
   → `.goodnotes` 파일이 만들어집니다.
4. 그 파일을 Windows PC로 옮긴 뒤 새 PDF와 함께 Riffle에 놓습니다.

> **PDF로 내보내면 안 됩니다.** PDF는 필기가 그림처럼 눌러 붙은 상태라 다시 편집할 수
> 없습니다. 반드시 **「Goodnotes 문서」** 로 내보내세요.

> ⚠️ **Goodnotes 6 지원은 실험 기능입니다.**
> 저장한 결과를 Goodnotes 앱에서 다시 열어 확인하는 검증이 아직 끝나지 않았습니다.
> **중요한 노트는 원본을 반드시 따로 보관한 뒤** 사용하세요.
> 잘 되는지/안 되는지 알려 주시면 큰 도움이 됩니다.

## 잘 안 될 때

| 이런 일이 | 이렇게 하세요 |
|---|---|
| 파란 「PC 보호」 창에서 막힘 | 위 «파란 경고창이 떴어요» 참고 — 「추가 정보」 → **[실행]** |
| 창이 열리다 마는 것 같음 | 창을 닫고 다시 실행해 보세요. 계속되면 `%LOCALAPPDATA%\Riffle\app.log` 파일을 보내 주시고, 그동안은 웹(<https://useriffle.onrender.com>)을 쓰세요 |
| 웹 주소가 한참 안 열림 | 서버가 깨어나는 중입니다. 1분쯤 기다렸다 새로 고침하세요 |
| 필기 옮기기에서 쪽이 안 맞음 | 두 문서의 **쪽 크기·회전**이 다르면 자동 정렬합니다. 그래도 이상하면 그 쪽 카드에서 **[다른 쪽]** 으로 짝을 고치세요. 카드에 없는 쪽은 **[연결 보기]** 에서 그 쪽을 눌러 고칩니다 |
| 「페이지 크기가 다른데 … 정렬 배율을 정할 수 없습니다」 | 두 PDF 중 하나가 거의 비어 있거나 스캔 품질이 낮아 기준을 못 잡은 경우입니다. 다른 PDF로 시도해 보세요 |
| 백신이 파일을 지움 | 백신에서 `Riffle-Setup-….exe` 를 예외 등록 후 다시 받으세요 |

문제가 계속되면 **문제 신고**를 남겨 주세요:
<https://github.com/kynbeen/riffle/issues>

무엇을 하다가 어떤 문구가 나왔는지 적어 주시면 가장 빠릅니다. 아래 기록 파일을 같이
첨부해 주시면 더 좋습니다.

```
%LOCALAPPDATA%\Riffle\app.log
```

(Windows 키 + R → 위 줄 붙여넣기 → Enter)

## 최신 버전으로 올리기

새 버전이 나오면 **설치할 때와 똑같이** 하면 됩니다. 덮어써서 설치되고, 설정이나 파일이
지워지지 않습니다. 방법 B의 명령 한 줄을 다시 실행해도 같습니다.

## 지우기

**설정 → 앱 → 설치된 앱** 에서 **Riffle** 를 찾아 **제거**를 누릅니다.
만들어 둔 PDF나 필기 파일은 지워지지 않습니다.
